# Credit Card Customer Churn Analysis

## Project Overview
Analyzed credit card customer data to understand customer demographics, transaction behavior, and attrition patterns using SQL and Power BI.

## Objectives
- Analyze customer profiles and segmentation.
- Compare transaction behavior between existing and attrited customers.
- Identify customer attrition patterns.
- Present business insights and recommendations.

## Tools & Technologies
- SQL (MySQL)
- Microsoft Power BI
- DAX
- Power Query

## Dataset
- Total records: 10,127
- Includes customer demographics, income categories, card categories, credit utilization, transaction activity, and customer status.

## Key Findings
- Customer attrition rate: 16.07%.
- Existing customers have an average transaction count of 68.67, compared with 44.93 for attrited customers.
- Average transaction amount is approximately 4.7K for existing customers and 3.1K for attrited customers.
- Blue is the most common card category, with 9,436 customers.

## Project Structure
- `sql/` — SQL queries and analysis.
- `powerbi/` — Power BI dashboard file.
- `screenshots/` — Dashboard screenshots.

## Business Recommendations
- Monitor declining customer transaction activity.
- Identify and review patterns among inactive customers.
- Use customer segmentation to support targeted retention strategies.

## Conclusion
This project demonstrates how SQL and Power BI can be used to analyze customer data, identify trends, and communicate business insights that support customer retention decisions.
